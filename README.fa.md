# مقایسه کد (Code Compare)

یک ابزار ساده و تعاملی تحت وب برای مقایسه کد شما با یک کد مرجع.

با استفاده از Code Compare می‌توانید کد خود را در کنار کد مرجع وارد کنید و به‌سرعت بررسی کنید که آیا با کد مرجع مطابقت دارد یا خیر. این پروژه از Monaco Editor برای فراهم کردن یک محیط کدنویسی مناسب استفاده می‌کند و به‌صورت کامل در مرورگر اجرا می‌شود.

## ✨ امکانات

- مقایسه کد شما با یک کد مرجع
- نمایش سریع نتیجه مقایسه
- ویرایشگر کد قدرتمند مبتنی بر Monaco Editor
- رابط کاربری ساده و کاربردی
- اجرای مستقیم در مرورگر
- بدون نیاز به Backend یا نصب نرم‌افزار اضافی
- سبک و سریع
- مناسب برای کار با HTML، CSS، JavaScript، JSON، PHP، Python و ++C

## 📖 نحوه کار

Code Compare دو ورودی برای کد در اختیار شما قرار می‌دهد:

1. **کد شما (Your Code)** — کدی که قصد دارید آن را بررسی کنید.
2. **کد مرجع (Reference Code)** — کد مورد انتظار یا کد مرجعی که می‌خواهید کد خود را با آن مقایسه کنید.

برنامه این دو کد را با یکدیگر مقایسه کرده و مشخص می‌کند که آیا کد شما با کد مرجع مطابقت دارد یا خیر.

این ابزار می‌تواند برای تمرین‌های برنامه‌نویسی، بررسی پاسخ تمرین‌ها و مقایسه پیاده‌سازی‌های مختلف مفید باشد.

## 💻 راه‌اندازی و اجرا

### اجرای پروژه به‌صورت لوکال

ابتدا ریپازیتوری را Clone کنید:

```bash
git clone https://github.com/mamsm-dev/code-compare.git
```

سپس وارد پوشه پروژه شوید:

```bash
cd code-compare
```

در نهایت فایل `index.html` را با مرورگر خود باز کنید.

برای اجرای پروژه نیازی به Package Manager یا فرآیند Build ندارید.

## 🌐 اجرای کاملاً تحت وب

Code Compare به‌گونه‌ای طراحی شده است که مستقیماً در مرورگر اجرا شود.

برای استفاده کافی است برنامه را باز کنید، کد خود و کد مرجع را وارد کنید و نتیجه مقایسه را مشاهده کنید.

## 🤝 مشارکت در پروژه

از مشارکت، پیشنهادها و بهبودهای پروژه استقبال می‌شود.

اگر ایده‌ای برای بهبود Code Compare دارید:

1. ریپازیتوری را Fork کنید.
2. یک Branch جدید ایجاد کنید:

   ```bash
   git checkout -b feature/your-feature
   ```

3. تغییرات خود را اعمال کنید.
4. تغییرات را Commit کنید:

   ```bash
   git commit -m "Add your feature"
   ```

5. Branch خود را Push کنید:

   ```bash
   git push origin feature/your-feature
   ```

6. یک Pull Request ایجاد کنید.
